THE COURIER GUY API — FAQ & TROUBLESHOOTING

Version 4.4 | Common developer questions and error checklist

FAQ

Do sandbox and live use the same key?

No. Pair each token with the matching environment endpoint.

Can ECO be used for every shipment?

No. Sandbox is permissive; production service availability depends on the route.

Note: As of 1 September 2026, Economy Road services (ECO / ECOR) are tiered by weight — 6 bands (ECO/R 1 to ECO/R 6, from up to 2kg through to up to 35kg) — across 3 zones (National = ECO, Regional = ECOR, and Regional-to-Regional = ECORR), rather than a single flat rate. See the current rate card for exact pricing per tier and zone.

How do I retrieve Zebra labels?

Use GET /shipments/label/stickers?format=zpl and pass an id or tracking_reference.

Can I send coordinates?

Yes if known. Otherwise leave them blank (omit them). Do not set them to null—null also causes errors. Never send 0.

What are PRI and PRIR?

PRI is the new name for PRI. PRIR is the new name for PRIR. Update service mappings and display labels accordingly.

What causes locker delivery to fail?

Locker/kiosk dimensions must not exceed 60 × 41 × 69 cm and 20 kg.

Common errors

API key invalid: check the Bearer token, Account Owner key creation, and matching environment/endpoint.

Account on hold or insufficient balance: resolve account status before retrying.

Address failure: send complete, valid address fields and correct province/zone.

Contact failure: use valid contact values; do not use a hyphen as a phone-number separator.

Service unavailable: choose a route-valid live service rather than relying on sandbox results.

422 Unprocessable Entity: validate required fields, request data types, parcel limits, declared value, service code, and allowed shipment action.

JSON model mismatch

rate_adjustments, surcharges, time_based_rate_adjustments, and extras can be arrays. Model them as arrays/lists of objects—not strings—because sandbox may return [] while live can return populated objects.

public List<RateAdjustment> rate_adjustments { get; set; }

Before escalating

Include endpoint, environment, HTTP status, timestamp, request ID, and sanitized request/response bodies.

Remove API keys and customer personal data before sending logs.
