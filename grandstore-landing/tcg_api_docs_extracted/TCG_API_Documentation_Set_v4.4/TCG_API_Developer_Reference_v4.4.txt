Implementation rules

Keep API keys server-side. Never expose them in browser code, repositories, or logs.

Validate fields and types before sending. An invalid type or missing required field cannot be repaired by retrying.

Use valid address data. Company is optional, but a company address must be recognisable by geocoding.

Leave lat/lng blank (omit them) when unknown. Do not send null—null also causes errors. Zero coordinates point to the Atlantic Ocean.

General parcel maximum: 800 × 800 × 800 cm and 2 000 kg. Use realistic dimensions and account for volumetric weight.

Services

Sandbox allows broad ECO testing; production does not. Request/choose a route-valid service in live.

Local: LPF or LPP; sandbox may use LSP where LPP is unavailable. National: ECO or PRI (formerly OVN). Regional: ECOR or PRIR (formerly OVNR). Regional-to-Regional: ECORR.

Note: As of 1 September 2026, Economy Road services (ECO / ECOR) are tiered by weight — 6 bands (ECO/R 1 to ECO/R 6, from up to 2kg through to up to 35kg) — across 3 zones (National = ECO, Regional = ECOR, and Regional-to-Regional = ECORR), rather than a single flat rate. See the current rate card for exact pricing per tier and zone.

Locker and kiosk rules

Locker or kiosk delivery limit: 60 × 41 × 69 cm and 20 kg.

A locker collection selection is for location reference, not a physical collection address. The sender must visit a locker; leave locker/kiosk collection blank where the integration supports it.

For locker, kiosk, and pickup-point integration support, email integrations@tcglocker.co.za. See the separate Locker API Examples guide for request patterns.

Labels and shipment notes

ZPL labels: GET /shipments/label/stickers?format=zpl using id or tracking_reference.

For more than 30 parcels, page label requests, for example: ?limit=20&offset=0.

Shipment notes: GET /v2/shipments/notes/external?shipment_id=123.
